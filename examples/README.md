# Examples / Örnekler

Runnable Python examples illustrating `tr-tarih` features. All examples run directly from a repository checkout without requiring package installation.

## Available examples

| File | Description |
| --- | --- |
| [`basic.py`](basic.py) | Quick start: core date, number, money parsing and formatting in four lines. |
| [`dates_and_times.py`](dates_and_times.py) | Natural language date expressions, day periods, relative time offsets, formatting styles and detailed parsing assumptions. |
| [`money_and_numbers.py`](money_and_numbers.py) | Number words and digits, converting numbers to words, Turkish lira parsing, formatting styles (symbol, suffix, words) and error handling. |

## Running the examples

From the project root:

```sh
# Basic example
python examples/basic.py

# Date & time parsing and formatting
python examples/dates_and_times.py

# Number & lira amount processing
python examples/money_and_numbers.py
```
